# Short-Horizon First-Seen Date

The short-horizon selector currently shows the current membership of All Stocks, Shortlist, Best aligned, and Latest 2-day finish, with a derived Fresh today view for new final-tab entries. The review workflow needs a small historical cue: for every stock shown in a tab, show the earliest of the last five completed sessions on which that stock met that tab's rules. This lets Kush identify how many sessions the setup has already been visible and decide whether to inspect the console immediately or look back.

The calculation will reuse the existing tab predicates and ranking functions against the already-loaded daily history, evaluating each of the five recent session cutoffs. The date will appear above the symbol in the Stock cell as `First seen DD Mon`, followed by `Close ±x.x% · High ±y.y%`. Close return compares the latest close with the first-seen close; High return compares the highest high in later sessions with the first-seen close, which keeps the GTT target reading post-signal and avoids counting the signal candle's earlier high. Positive values are green, negative values are red, and positive returns at or above 5% are bold. For All Stocks the date naturally resolves to the oldest session in the five-session window, while filtered tabs reflect actual tab entry. No scanner thresholds or ranking rules will change.
A derived `Fresh today` tab follows `Latest 2-day finish`. It shows only rows whose first-seen date for that final tab equals the current completed session, separating newly qualified stocks from rows already visible in the rolling five-session window.

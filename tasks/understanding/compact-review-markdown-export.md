# Compact review Markdown export

The compact page is intentionally dense for human scanning, but an AI needs the underlying rows and field definitions to enrich the review with outside context. The export action downloads a Markdown file containing the current snapshot, breakout levels, four-week structure, top-volume effort/result rows, saved observations, and the latest 60 daily OHLC/RSI14/ROC9/volume/delivery rows.

The export stays evidence-only: it includes calculation notes and dates, but does not add a buy/sell verdict. The filename includes the symbol and latest candle date so exported reviews remain identifiable.

# Compact Review Four-Week Summary

The compact stock review already shows one stock's four-week flow. The requested companion view is a fast discovery queue: it must remain idle until one or more watchlists are selected, then show stocks whose current week's low is within 1% of the immediately preceding week's low. The result only needs the stock, both low prices and dates, and the measured gap; it is an evidence cue for floor review, not an automatic accumulation or buy signal.

The implementation will stay frontend-only and reuse `/api/strategy/weekly-price-review/watchlists` plus the existing per-watchlist weekly scan endpoint. The compact review remains the default tab. The new 4W Summary tab will deduplicate symbols across selected watchlists, use the latest two observed Monday-to-Sunday groups, show an explicit idle/loading/error/empty state, and let the user open the same symbol back in the compact review.

Implemented as a compact-review tab with an explicit watchlist-first flow and Ant Design multi-select. The 4W Summary now includes the maximum move over the next five completed sessions after last week's low, and a companion `5D >5%` tab filters to strict upside moves above 5%. Focused summary and utility tests pass, and the frontend production build passes.

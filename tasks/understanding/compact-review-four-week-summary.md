# Compact Review Four-Week Summary

The compact stock review already shows one stock's four-week flow. The requested companion view is a fast discovery queue: by default it should scan all available watchlists, while still allowing one or more watchlists to be selected, and show stocks whose current week's low is within 1% of the immediately preceding week's low. The result only needs the stock, both low prices and dates, and the measured gap; it is an evidence cue for floor review, not an automatic accumulation or buy signal.

The implementation will stay frontend-only and reuse `/api/strategy/weekly-price-review/watchlists` plus the existing per-watchlist weekly scan endpoint. The compact review remains the default tab. The new 4W Summary tab will deduplicate symbols across selected watchlists, use the latest two observed Monday-to-Sunday groups, show an explicit loading/error/empty state, and let the user open the same symbol back in the compact review.

Implemented as a compact-review tab with an all-watchlists default and Ant Design multi-select override. The summary uses a new typed two-week helper with an inclusive 1% threshold, displays current/last low prices and weekday-formatted dates, and links matching symbols back to the stock-review tab. Focused summary and utility tests pass, and the frontend production build passes. The existing broad compact-page test still contains unrelated stale assertions about paper-trade age and a removed header CSS class.

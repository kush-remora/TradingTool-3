# Daily Low Trigger Backtest

This experiment tests whether a confirmed five-session low-to-high cycle creates a repeatable retest trade. At the start of each session, the engine inspects the previous 10 completed sessions as two consecutive five-session cycles. The latest cycle must independently reach the fixed +5% confirmation move from its low to its high; the lower low from the latest and earlier cycles becomes the independent limit-order reference.

The low must occur before the high. If the low and high are on the same candle, a green candle is assumed to travel low-then-high; red and doji candles do not qualify as same-day low-to-high cycles. The limit offset is configurable from 0.5% to 1.0% and defaults to 0.5%. The exit target is configurable from 0.1% to 100.0% and defaults to 5.0%. Each qualifying day creates its own order, so consecutive days can overlap. The order remains active for four trading sessions. For a filled trade, the target is the configured percentage above that buying day's actual low, while realized P/L is still measured from the actual fill price; if the target is not reached, the trade exits at the fourth trading-session close. For no-fill diagnostics, the displayed hypothetical target continues to use the anchor low because there is no buying day. The 52-week-high filter is removed for this experiment. The run can evaluate a full watchlist or one selected stock.

The audit view keeps the main row focused on cycle, entry, peak-after-entry, and result. Expand a row for raw verification inputs: previous-ten-session dates, lower reference low/date, latest-cycle low/high/move, sequence assumption, limit window, order-window low, fill-day metrics, fourth-session hypothetical no-fill P/L, peak return, target reachability, and outcome/P&L. Filled rows also have a compact daily-detail button. It shows five trading sessions before the previous cycle start through five trading sessions after exit, highlights the entry and exit rows, and exposes OHLC, volume versus the preceding 10-session average, delivery, a visual LOW/MID/HIGH close-position cell with candle direction, close change, and the daily low-to-high percentage range. The detail modal does not use a blocking mask so the persistent buy/sell calculator remains usable. For a single-stock run, the summary also shows the simple sum of realized trade returns and total holding sessions; weekends and holidays are excluded from holding time. No-fill rows intentionally have no trade-detail button because there is no actual entry or exit row to highlight.

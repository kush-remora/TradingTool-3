# Delivery Breakout Result vs Effort

The Delivery Breakout Validation screen currently shows event rows identified by unusual volume or delivery, but it does not provide a focused view for quiet price movement. The requested workflow is to keep the existing complete event table and add a second tab that shows only event days where the stock's intraday low-to-high movement is below 3%.

The rule is defined as `(event high - event low) / event low * 100 < 3`. It uses the selected event candle's absolute low-to-high spread, not delivery percentage or close-to-close change. This is a client-side presentation filter because the API already returns `event_low` and `event_high`; no backend contract change is required.

Implemented on 2026-08-26 with four funnel tabs: `All Stocks` preserves the existing event table, `Result vs Effort` applies the event Low→High `<3%` rule plus a positive pre-event 10-session change below 10%, `At Least 10% Below 52W High` refines Tab 2 by keeping only stocks whose current price is at least 10% below the event-date 52-week high, and `20D Accumulation Candidate` refines Tab 3 using backend-computed pre-event metrics. The accumulation rule uses the prior 20 trading sessions (about one month), requiring at least 10 of 20 sessions to have Low→High movement at most 2% and the full 20-session range to be at most 10%. Existing event-type and ratio filters continue to apply within every tab. Focused frontend tests passed (5 tests), backend analyzer tests passed (7 tests), and the production frontend build passed with the existing large-chunk warning.

# Compact review weekly floor distance

The four-week flow already shows the low band and low/high structure, but the reader still has to compare that band with the current price mentally. Add one neutral `Gap` value using the distance from the upper edge of the low band. This is location context, not a buy verdict; a negative value means current price is below the band.

The same pass tightens the secondary breakout block: its label, date, level, and distance rows share a left edge and use a fixed readable width.

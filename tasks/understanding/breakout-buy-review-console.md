# Breakout Buy Review console

Build a dedicated historical review page at `console/breakout-buy-review`. The user selects a symbol and completed trading date; the page first shows the five breakout-day quality rules, then that session's causal structure state, raw candle/evidence values, per-rule verdicts, and one plain-language overall decision. The page must support fresh-breakout dates, ceiling/test dates, and dates after a breakout without pretending every reviewed date was an entry signal.

The backend must replay candles only through the selected date so later price action cannot change the answer. Prior-volume and prior-delivery baselines exclude the selected session. Missing delivery is shown explicitly and produces a cautious `WAIT`, not an invented pass/fail. The Adaptive Breakout scanner will add a compact link that opens this page in a new tab, defaulting to the last fresh-breakout date when available and otherwise the row's latest completed candle date. V1 intentionally excludes next-day gap, stop placement, fundamentals, and order execution; those belong to the broader buying guide, not breakout-day quality.

Implemented as a dedicated console plus scanner deep link. The selected session exposes OHLC, floor, peak, breakout line, ATR, SMA 50/200, volume, and delivery beside the rule verdicts. Fresh-breakout dates aggregate to `PASS`, `WAIT`, or `REJECT`; ceiling, rebound, and continuation dates remain `CONTEXT_ONLY`. Focused backend and frontend tests plus module/build checks validate the flow.

Extend this same page with two compact sections. Chart context must causally show price versus the 50/200 SMA, their direction, the nearest overhead obstacle, and ATR-normalized room. Next-morning execution accepts an opening price and applies the documented ATR zones: up to 0.25 ATR can be considered, 0.25–0.50 ATR waits for a limit/pullback, above 0.50 ATR is not chased, and an open below the line is rejected. A one-line buy/sell/% calculator belongs directly underneath. These remain review aids, not automatic order instructions.

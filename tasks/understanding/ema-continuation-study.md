# EMA Continuation Study — Understanding

The user wants a daily study with two buy strategies. Strategy 1 buys the EMA10/EMA20 cross when price is above a rising SMA200 and setup-day volume is at least 1.5× the prior 20-session average. Strategy 2 uses that EMA cross as a setup, waits for a 5–15 session consolidation base, and buys a close above the base high; the base must be no wider than 12% and breakout-day volume is context only. The previous raw EMA20 touch/reclaim entry is intentionally removed because it generated buy signals inside consolidation. The console will run either one selected watchlist member for detailed chart review or the complete selected watchlist for a summary table. The chart remains tied to the selected stock, with study dates from 2026-01-01 through the latest available completed session and a live current-session snapshot.

Version 1 deliberately keeps execution daily. It will fetch indicator warm-up candles before 2026-01-01, require only the EMA setup cross to meet the 1.5× previous-20-session volume condition, represent a study entry at the next tradable session open, scan subsequent daily highs for first hits of 5%, 10%, and 20% targets, and show close-near-high percentage plus close-above-EMA20 distance in ATR14 units. Exits are intentionally out of scope. Kite 5-minute candles remain a later execution-detail layer, so this feature will not reconstruct intraday entries or trailing exits.

The CGPOWER review on 12–18 March 2026 is the acceptance example: March 10 is a valid EMA-cross setup, while the March 18 EMA20 touch/reclaim is not a buy because price never broke the consolidation high. The study must expose each breakout's setup date, base start/end, base high/low, and base width so the entry is auditable.

Implementation extends the existing Kotlin strategy/API patterns and React console patterns, preserves unrelated worktree changes, adds focused engine/API/UI coverage, and validates manually with NETWEB and a complete watchlist run.

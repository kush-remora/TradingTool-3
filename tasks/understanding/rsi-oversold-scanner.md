# RSI low scanner — current understanding

Replace the RSI oversold backtest with a simple live scanner. The user selects one or more watchlists, the scanner unions their active stocks, calculates daily RSI-14, and uses the prior 200 trading sessions to establish each stock's minimum RSI. A stock qualifies when a day in the latest 20 trading sessions has `RSI + 1` equal to that prior-200-session minimum; one row uses the most recent qualifying day, with its date, RSI, closing price, and volume, plus the latest available candle fields for fallback display. No target, entry, recovery, or backtest logic remains.

The UI enriches each historical row with the existing live quote feed. Current LTP and current volume use the quote when available and fall back to the latest daily close/volume; percentage change is calculated from the signal candle's close to that displayed current price. The `+1` comparison is made after rounding RSI values to two decimals to make equality deterministic. The API distinguishes stocks with insufficient history from stocks that were evaluated but had no signal; no-signal results are normal and should not show an error. Validation should cover the prior-200-session baseline, exclusion of the 20-session signal window from that baseline, and the multi-watchlist API/UI flow.

# Adaptive Breakout Follow-Through Console

## Why it was built

The adaptive-breakout console needed a direct way to judge whether a completed breakout still has an orderly follow-through window. A stock can remain interesting after the first breakout when price has not become excessively extended and later volume has not overwhelmed the original move.

## What was implemented

- Added an `Already in breakout zone` table for every `BREAKOUT_CONTINUATION` stock.
- Each stock is displayed as two stacked evidence rows: `Breakout day` and `Highest volume after breakout`.
- Both rows show close price, volume, volume versus the preceding 10 completed sessions, and close position within the day's low-high range.
- Added stock-level current price, return from breakout close, breakout date, and elapsed calendar days.
- Added exact breakout and highest-post-breakout evidence to the backend response so breakouts older than the UI's 260-session replay window still appear correctly.
- Kept the existing structure table and 20D evidence modal available below the new focused view.

## Key decisions and tradeoffs

- The highest-volume comparison scans all available candle history after the breakout, while the existing 20D modal remains a recent-session drill-down.
- Current price uses the live quote when available and otherwise the latest completed close.
- The table is evidence-only; it does not turn low later volume into a buy signal.
- Backend evidence is returned as two compact day objects instead of expanding the entire raw replay payload.

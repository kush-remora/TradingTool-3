# Volume Event Confirmation Backtest — 2026-08-10

## Why it was built

The volume-event page should be as compact as the six-month breakout backtest: one rule, a small set of inputs, and a direct trade table.

## What was implemented

- Removed the RSI controls and reduced the page to the single volume-shocker price-confirmation rule.
- Added multi-watchlist selection, a target percentage input defaulting to 10%, and a fixed six-month backtest window.
- Added a compact trade table with symbol, signal/event date, entry, target, status, exit, holding days, Current LTP, and percentage change from entry.
- Open trades show `OPEN`, current LTP, and current percentage change; target-hit trades show their exit details.

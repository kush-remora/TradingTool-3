# Volume Event Review strongest-event date sorting

## Why it was built

Make the Volume Event Review easier to sequence chronologically when comparing the strongest raw volume event across stocks.

## Implemented

- Made the `Strongest event` stock-table column sortable by the displayed strongest event date.
- Added a focused frontend regression test covering the ascending date sort interaction.

## Decisions and tradeoffs

- The comparator uses the existing ISO-formatted event date from the strongest event, preserving the page's current event ranking by volume multiplier.
- Stocks without a qualifying event sort safely using an empty date value.

# Stock History CSV console

## Why it was built

Provide a quick way to download one NSE stock's recent daily data for Wyckoff review and offline analysis without creating a second data pipeline.

## Implemented

- Added a `Stock History CSV` console route and sidebar entry.
- Added stock selection from the existing NSE equity instrument cache.
- Added 1-, 3-, and 6-month lookback options.
- Previewed daily date, weekday, OHLC, open-to-high %, open-to-close %, volume, delivery volume, and delivery %.
- Joined delivery rows by date and left delivery fields blank when unavailable.
- Added Excel-friendly UTF-8 BOM CSV download, with rows exported oldest-to-newest and the preview shown latest-first.

## Decisions and tradeoffs

- Reused `/api/stocks/by-symbol/{symbol}/detail?days=` because it already returns the required daily candles and delivery data; no backend contract was added.
- Lookbacks request 31, 93, and 186 calendar days, staying within the backend's 200-day endpoint limit and yielding roughly 1, 3, and 6 trading months.
- The current backend exposes 75 delivery-history days, so older 6-month rows can legitimately have blank delivery columns.

## Week-over-week price structure arrows

### Why it was built

Show whether the reviewed stock is forming higher highs/higher lows, lower highs/lower lows, or a mixed/sideways structure across the displayed weeks.

### Implemented

- Added shared `UP`, `DOWN`, and `SIDEWAYS` week-over-week classification.
- Added accessible `↑ Up`, `↓ Down`, and `→ Sideways` indicators to both review tables.
- The first displayed week remains neutral because it has no comparison week.

## Weekly low-day effort and delivery cue

### Why it was built

Make the existing three/four-week review faster to scan for a Wyckoff-style accumulation clue: compare effort on the weekly low day with effort on the weekly high day.

### Implemented

- Added a shared weekly-summary flag when the low-price day's volume and delivery percentage are both strictly higher than the high-price day's values in the same week.
- Added a `Cue` column and pale-green row highlight to the single-stock and watchlist review tables.
- Left missing delivery, equal values, and failed comparisons neutral.

# Watchlist weekly-low alignment summary

## Why it was built

Add one separate evidence view to the Three-Week Stock Review + Current Week watchlist page for any two adjacent displayed weeks whose weekly lows are within 1%. This surfaces tightly aligned price floors for manual Wyckoff review without turning the observation into a score or recommendation.

## What was implemented

- Added a typed utility that compares only adjacent weekly summaries.
- Uses an absolute percentage difference relative to the earlier week's low, with a maximum of 1.00%.
- Added a compact `Weekly low alignment summary` table below the existing watchlist evidence summary.
- Shows every qualifying pair for each matching stock, including multiple pairs for one stock.
- Shows an explicit empty state when the selected watchlist has no qualifying pair.

## Decisions and tradeoffs

- Kept the calculation in the frontend because the page already receives and groups the daily candles into the displayed four weekly summaries.
- Limited the evidence to the displayed weeks, including the current week when it is present.
- Listed only matching stocks in the table while keeping the explanation raw and non-prescriptive.

# Base Consolidation Low-Hit Scanner

## Feature and purpose

Added an observation-first scanner that lets Kush validate repeated daily-low support across one selected watchlist before deciding which stock deserves individual review.

## What was implemented

- Added **Base Consolidation Scanner** navigation and a watchlist selector.
- Extended the read-only candle window to 60 calendar days so the frontend can evaluate 30 completed trading sessions.
- Renders ten raw rows per stock with only Stock, Reference date, Reference low, and Hits in previous 20 sessions.
- Highlights the strongest rows for each stock and the top 10 stocks by strongest hit count without filtering any data.
- Added a stock link that opens Three-Week Stock Review + Current Week with that stock preselected.

## Key decisions

- Reused the established index-constituent groups as the selectable watchlists; this includes the curated Groww high-quality watchlist where present.
- Uses the ten newest daily lows as candidates and compares each with its immediately preceding 20 completed sessions.
- Counts a hit inclusively when the historical low is within +/-1% of the candidate low.
- Kept the scanner raw and non-prescriptive; highlighting is only a validation aid and does not label a base or produce a buy signal.

# Weekly Price Watchlist Scanner

## Feature and purpose

Added an observation-first scanner that lets Kush compare the latest three completed weeks plus the current week across one selected watchlist or universe, before deciding which stock deserves individual review.

## What was implemented

- Added **Weekly Price Scanner** navigation and a watchlist selector.
- Added read-only endpoints to list available groups and return each member's latest 35 calendar days of cached OHLC with bounded parallel reads.
- Renders one compact card per stock with four weekly Low / Low date-day / High / High date-day / Range rows.
- Added **Open review**, which opens Three-Week Stock Review in a new tab with that stock preselected.
- Added the shared fixed lower-right Buy / Sell / Change calculator to the scanner as well as the detail review.

## Key decisions

- Reused the established index-constituent groups as the selectable watchlists; this includes the curated Groww high-quality watchlist where present.
- Reused the existing frontend weekly-summary utility so the scanner and detailed screen calculate weekly highs, lows, and range identically.
- Kept the scanner price-only and non-prescriptive; it does not label a base or produce a buy signal.
- Reused one calculator component so all three values calculate the same way in both screens.

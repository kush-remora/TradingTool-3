# Three-week watchlist review restored

## Feature and purpose

Restored the watchlist-level **Three-Week Stock Review + Current Week** workflow that had become difficult to find after the former weekly price screen was converted into the Base Consolidation Low-Hit Scanner.

## What was implemented

- Added a separate sidebar route with the explicit `Three-Week Stock Review + Current Week` label.
- Reused the existing watchlist endpoint and weekly grouping utility.
- Shows four weekly rows per stock: the prior three completed weeks plus the latest/current week.
- Keeps delivery percentage and volume beside each weekly low/high date.
- Keeps the Base Consolidation Scanner available under its current route.
- Preserves the existing single-stock review button for deeper daily inspection.

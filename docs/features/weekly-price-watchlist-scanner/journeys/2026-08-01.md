# Base Consolidation Low-Hit Scanner

## Feature and purpose

Converted the existing weekly price watchlist screen into a raw validation view for repeated daily-low support. The purpose is to inspect the underlying counts first, before deciding whether a cleaner base-strength rule is justified.

## What was implemented

- Kept the existing watchlist dropdown and watchlist-backed stock universe.
- Uses the latest 10 completed daily lows for each stock.
- For each candidate low, counts previous daily lows within +/-1% across the preceding 20 completed sessions.
- Shows exactly four table columns: Stock, Reference date, Reference low, and Hits in previous 20 sessions.
- Highlights the strongest rows for each stock and the top 10 stocks with valid hit counts.
- Links every stock row to **Three-Week Stock Review + Current Week**.
- Makes the stock card header, such as `BEL · Bharat Electronics`, open the corresponding NSE chart in Kite using the instrument token.
- Extended the backend candle window from 35 to 60 calendar days so the frontend has enough history for 30 trading sessions.

## Key decisions and tradeoffs

- Kept the calculation in a small pure frontend utility because V1 is an evidence-validation screen and the existing API already returns daily candles.
- Excludes the candidate session from its own history and returns `—` when 20 prior sessions are unavailable.
- Does not collapse nearby lows, score a stock, add volume/context filters, or produce a trade signal.

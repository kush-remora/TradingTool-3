# Delivery Breakout Watchlist 10-Day Validation

## Feature and purpose

Changed Delivery Breakout Validation so Kush can select a saved watchlist and review unusual volume and delivery behavior over the latest ten trading sessions.

## Implemented

- Added watchlist resolution through active `index_constituents` memberships.
- Added optional end-date support with latest-date fallback.
- Replaced the previous-day `3x volume AND 3x delivery` rule with independent `2x preceding-10-session-average` checks.
- Added `BOTH`, `DELIVERY_ONLY`, and `VOLUME_ONLY` event classification.
- Added one event row per stock-day with current values, 10-session averages, ratios, delivery percentage, and price context.
- Added watchlist/date controls and summary counts to the React console.
- Continued ETF exclusion without adding a database migration.

## Key decisions

- The scan uses trading sessions rather than calendar days.
- Delivery quantity drives delivery-shock detection; delivery percentage remains review context.
- Stocks without events are omitted from the event table and counted in the summary.

# Silent Breakout Backtest

## Why

Evaluate any imported Chartink signal solely by its symbol and signal date. The screener's volume rule remains external; this tool shows the point-in-time price context and the price action that followed.

## Implemented

- Added a dedicated `Silent Breakout Backtest` console page with a CSV upload accepting `symbol` and `date`.
- Added a point-in-time backend analysis using the signal candle and its prior daily candles only.
- Added 52-week-high distance, 20-session return, 200-SMA distance, and a late-stage risk flag.
- Defined late-stage risk as a 20-session advance of at least 20%.
- Added 20/40-session forward returns and 40-session maximum gain/drawdown as outcome-only metrics.
- Added a per-row, non-persisted manual chart verdict: Accumulation, Distribution, or Unclear.
- Changed incomplete 200-day/52-week histories from an exclusion to a `Partial history` status. The 52-week high and moving average use all available prior candles; ROC20 remains unavailable only until 20 prior sessions exist.
- Added a per-row Review action that opens the existing Three-Week Stock Review for the selected symbol.
- Made the signal-table column header sticky beneath the application header during vertical scrolling.
- Added a target-% control. Entry is the next trading day's open; the target column reports whether that target was reached within 40 trading sessions and the trading days taken.
- Added the maximum delivery percentage from the five trading sessions before each signal.
- Added the next-session-open entry price as a sortable table column for backtest validation.
- Added a five-session post-signal dip diagnostic: the lowest low, its move from the signal close, and trading days until that low.
- Added a default-on Blind review toggle that hides all post-signal outcomes before chart review.
- Preserve duplicate `symbol` and `date` rows from an upload as separate observations.
- Added optional signal-month and Large/Mid/Small-cap filters, using the uploaded CSV's date and market-cap columns.

## Decisions

- Do not reconstruct or compare the source file's volume multiple. A row is only a historical signal date.
- Never use post-signal candles to classify the signal; future data is used only for outcome metrics.
- The late-stage flag is a review aid, not a claim that every extended move is Wyckoff distribution.
- Retained 52-week-high and 200-SMA data as visual chart context rather than hard exclusions.

## Validation

- The focused Kotlin suite also confirms duplicate CSV rows are preserved as separate signals.
- The focused Kotlin suite confirms that selected month and market-cap filters retain only matching CSV rows.

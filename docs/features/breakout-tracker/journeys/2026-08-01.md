# Breakout Tracker CSV Export

## Why

Kush needs a portable snapshot of every candidate tracked in Breakout Tracker for review and offline analysis.

## Implemented

- Added a `Download CSV` button to the tracked candidates card.
- Exported all persisted entry fields, notes, and available last-price/performance values.
- Added CSV escaping for commas, quotes, and multiline notes, plus a UTF-8 BOM for spreadsheet compatibility.
- Kept the export client-side because the page already has the complete entry list.

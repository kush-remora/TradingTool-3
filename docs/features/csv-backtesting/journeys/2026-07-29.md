# Target Outcome Reporting

## Why

CSV backtesting must measure whether a configured target was reached, not whether an exit happened to be profitable.

## Implemented

- Added an explicit target-hit outcome to CSV backtest exits and trade results.
- Replaced monthly Win/Loss/Win Rate with Target Hit, Stop Hit, Unresolved, and Target Hit Rate.
- Updated the filtered Trade Details summary to use the same target-driven definition.
- Moved V2 Vol Spike and V2 Run % to Trade Details columns 5 and 6.

## Decision

An exit at the maximum holding period or an open trade is unresolved even when it has positive P&L. Only a target exit is a success.

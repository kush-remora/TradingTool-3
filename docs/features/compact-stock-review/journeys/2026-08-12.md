# Compact stock review: intraday dip visibility

## Why

Intraday review needs the maximum downside from the session open to the session low immediately visible. Comparing the Open and Low cells manually is slow when deciding whether a pullback is tradable.

## Implemented

- Added `openToLowPct`, derived from the existing daily candle as low versus open.
- Added `Dip O → L` to the primary compact review strip, showing the open, low, signed rupee move, and signed percentage.
- Added a bold `LTP` block to the primary strip with a live-feed/latest-close source hint.
- Added `Open → Low` to Recent tape and the expanded daily tape.
- Included the same measure in the Markdown snapshot and daily candle export.

## Decisions and tradeoffs

The value is signed rather than converted to an absolute positive “dip” so downside remains visually unambiguous. No threshold or buy/sell recommendation was added; the metric is evidence for the user’s intraday judgment.

## Validation

Focused unit and page tests cover the calculation, live primary-strip visibility, tape column, and Markdown export: 9 tests passed. The frontend production build passed. The full frontend suite passed 158/162 tests; four unrelated existing page tests timed out at the default 5-second limit.

## Follow-ups

If intraday data is later available, this daily open-to-low field should remain as the session context while a separate live session drawdown metric can update from the live price.

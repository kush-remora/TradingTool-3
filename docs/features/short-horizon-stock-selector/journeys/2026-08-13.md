# 5-Day Stock Selector

## Why

The existing Compact Stock Review is the detailed evidence screen. Kush needed a lighter watchlist-level screen that quickly identifies stocks worth opening when the intended trade is one to five days with a 5% to 10% objective.

## Implemented

- Added a `5-Day Stock Selector` console route and sidebar entry.
- Reused the existing daily watchlist scan; no new backend endpoint was needed.
- Added a compact table with the latest close, historical `+5% in 5D` count/rate, latest close position from low to high, and direction.
- Added two tabs: the full watchlist and an adaptive Shortlist view.
- Added a Core tab containing only stocks selected by both the 20-day and recent 6-day rankings.
- Added both the full 20-day and recent 6-day successful-day counts to the full-watchlist view.
- Added a minimum evidence gate before ranking: at least 5 successful days out of 20 and at least 2 successful days out of the recent 6 eligible days. A stock cannot enter just because it ranks highly in a weak watchlist.
- Added a price-position guard before ranking: the latest close must be no more than 10% below the recent 20-session high. This removes stocks where the recent move may already be materially weak or late.
- Added a current-weakness guard: reject only when the last 3 closes fall in a row and the latest close breaks below the previous 5-session low. Three red candles alone do not reject a stock.
- The original watchlist size sets the per-ranking limit: top `ceil(20% of the original watchlist)`, capped at 20, from each count. The guards only remove stocks; they do not shrink the limit. This keeps the combined list at 40 stocks or fewer without forcing weak stocks into the list.
- Added Shortlist context fields for the recent 20-session high, signed pullback from that high, and the largest volume bar in the latest five sessions versus the prior 20-session average.
- Added Core context for the 52-week high and distance from it; this orders the Core list but is not another rejection rule.
- Added current 5-session and 20-session price moves to Core, with direction arrows; these are context only and do not change membership.
- Added Core context for `Strong finishes`: the count of the latest five completed candles whose close finished above 60% of that candle's high–low range. This is descriptive pressure evidence only and does not change membership or ranking.
- Added Core context for `Move quality`, classifying the latest five candles as `Clean`, `Mixed`, or `Wild` using close progression, strong finishes, direction changes, and path efficiency. It is context only and does not change membership or ranking.
- Made `Latest finish` sortable by the close's percentage position within the latest candle's high–low range.
- Reworked the `Details` modal to show the latest 20 completed sessions, newest first, with date, OHLC, close-to-close change, close position within the daily range, and distance from the day's high. Historical 5D reach examples are no longer the primary detail view.
- Made the read-only `Details` modal modeless by removing its blocking mask, so the global buy/sell calculator remains usable while details are open.
- Clarified the reach terminology in the table, rule explanation, method note, and details modal: `5D reach` means price touched +5% within the next five trading sessions from a tested starting close; `Recent tested 6D` means the six latest eligible starting days.
- Added a sortable `Strong finishes` column to All Stocks, showing the count out of five plus five filled/empty dots in newest-first order. Filled dots mean the candle closed in the upper 40% of its daily range; hover still exposes the date and sequence position.
- Added one sortable `Move now` column to All Stocks with non-overlapping `Now 5D`, `Prior 5D`, and `Earlier 10D` close-to-close movement. The cell summarizes latest-versus-prior-5D pace and keeps the hidden 20D total and extension detail in hover text.
- Added a sortable `Exit pressure` warning to Shortlist and Core. It now evaluates a three-session push/failure sequence against the preceding 10-session volume average: `Quiet`, `Watch`, or `Caution` when a meaningful 1.5x strong-close push is followed by weak failure. It remains context only and does not imply confirmed distribution or change selection.
- Validation: focused selector tests passed with 20 tests, and the production frontend build passed. The page test confirms the column appears once in Shortlist and Core and remains sortable.
- Reordered All Stocks so 10D/20D move, Strong finishes, Move quality, and Exit pressure lead the reading order; 5D reach remains visible as historical context. Added a `Volume vs 10D avg` multiplier to the recent-details popup.
- Added a `How to read Tab 1` button that loads a backend-owned JSON guide into a reusable popup table. The guide source is `core/src/main/resources/short_horizon_selector/tab_one_guide.json`, and the endpoint/UI tests plus frontend build and backend module compile passed.
- Reworked the All Stocks move column into a compact stacked `Move now` cell with `Now 5D`, `Prior 5D`, and `Earlier 10D` shown one below the other. Green/red color communicates each bucket's direction, an arrow compares the latest 5D with the prior 5D using a 1 percentage-point tolerance, and the Latest close cell shows a small amber warning when the hidden 20D total is above 25% for extension review. Detailed total and bucket math remains available on hover to reduce table clutter.
- Reduced visual weight in the stacked `Move now` cell: repeated `5D`, `10D`, and `20D` labels are now small and light, while the percentage values remain prominent to reduce row-level cognitive load.
- Placed `Strong finishes` beside `Latest finish` on Tab 1. Reduced the Latest finish column width so repeated five-session buyer control and the most recent candle can be compared together without expanding the table.
- Added `20D` total movement and distance from the recent high under `Latest close`. An amber caution symbol appears only when the 20D move is strictly above 25%; it is an extension warning and does not filter or reject the stock.
- Refined `Exit pressure` to model the Composite Man sequence: a strong-close volume push can attract buyers, but the next-session failure creates Caution only when the push volume reaches 1.5x the preceding 10-session average. A strong close followed by weak low-volume follow-through remains Watch, not confirmed supply.
- Added a `Review` action that opens the existing Compact Stock Review.
- Added pure calculation tests and a page-flow test.

## Decisions and tradeoffs

- A successful example means the next five available trading-session highs reached at least 5% above the starting close.
- Only the latest 20 usable starting days are considered; the denominator is shown when fewer are available.
- A close at or above 75% of the day’s low-to-high range is `HIGH`, at or below 25% is `LOW`, and the rest is `MID`.
- The screen intentionally has no combined score, buy label, rejection metric, 10% metric, or intraday data.
- The volume and pullback fields are descriptive evidence only; a large volume bar is not labelled confirmed distribution. The three-close breakdown rule is the current structural weakness guard.

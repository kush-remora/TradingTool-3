# EMA Continuation Study — 2026-08-22

## Why it was built

The user wanted to study a daily EMA continuation idea on one stock selected from a watchlist, starting 1 January 2026. Daily candles are the deliberate V1 scope; Kite 5-minute data remains a future execution-detail layer.

## Implemented

- Added a standalone Kotlin EMA cross entry engine and service.
- Added watchlist, study, and current-session API endpoints.
- Added a complete-watchlist study endpoint that analyzes every active member with bounded parallel candle reads and returns one sortable summary row per stock, including errors for insufficient history.
- Reused the existing watchlist-member endpoint for the one-stock selector.
- Added the React console at `/console/ema-continuation` with a single-stock chart mode and complete-watchlist summary mode. The chart remains tied to the selected stock and includes daily candles, 10 EMA/20 EMA/200 SMA overlays, EMA setup and base-breakout markers, auditable base fields, forward performance, and a current quote panel.
- Current-session data refreshes every five minutes only during Indian equity market hours and cleans up its timer on unmount.
- Signal and target-performance tables expose sortable, searchable exact-value filters for every displayed column.
- The watchlist result table also exposes sorting and exact-value filtering for status, identity, strategy counts, latest signal, and failure details. Clicking a row selects that stock for the detailed study button.

## Key decisions

- Study candles fetch 420 calendar days of warm-up history and require 220 completed sessions before the study start for the 200 SMA and 20-session slope.
- An EMA cross requires the daily close to move from below at least one EMA to above both the 10 EMA and 20 EMA.
- EMA-cross setups additionally require current volume to be at least 1.5× the average volume of the previous 20 sessions, excluding the signal day.
- A buy signal requires a prior EMA setup, a 5–15 session base no wider than 12%, and a daily close above the base high and both EMAs. Breakout-day volume remains visible as context but is not an entry gate. Raw EMA20 touch/reclaim is no longer an entry condition.
- The EMA-cross setup itself remains a separate immediate-buy strategy; the response and table report EMA-cross and base-breakout entries together with distinct types.
- Entries are represented by the next tradable session open. For each 5%, 10%, and 20% target, the engine scans each subsequent daily high and records the first session that reaches the target; no exit is simulated.
- Added two candle-quality metrics: close-near-high percentage = `(close - low) / (high - low) × 100`, and close-above-EMA20 ATR distance = `(close - EMA20) / ATR14` using Wilder ATR14.

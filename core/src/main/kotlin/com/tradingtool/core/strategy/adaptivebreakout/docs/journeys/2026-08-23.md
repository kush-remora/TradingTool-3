# Adaptive Breakout recent broken filter — 2026-08-23

## Why it was built

The scanner showed the last fresh-breakout date for already-broken stocks, but did not provide a direct way to isolate breakouts from the recent 30-day window.

## Implemented

- Added a `Broken ≤30d` status bucket to the summary strip.
- Filtered the bucket to `BREAKOUT_CONTINUATION` rows whose breakout age is 0–30 calendar days from the row's latest scan date.
- Added the breakout age beside the existing breakout date, such as `9d ago · 05 Aug 2026`.
- Kept the existing `Already broken` bucket and breakout status unchanged.

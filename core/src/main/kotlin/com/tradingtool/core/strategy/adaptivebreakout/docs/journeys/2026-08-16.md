# Adaptive breakout causal swing revision — 2026-08-16

## Why

The first engine used today's ATR to confirm old extremes and required a second ceiling test. That allowed volatility changes and UI event precedence to alter the structure in ways that were difficult to explain. The revision aligns the replay with a causal ATR ZigZag while keeping breakout confirmation close-based.

## Implemented

- Both upward and downward turns now default to a symmetric 1.0 ATR.
- Reversal distance uses ATR from the candidate floor or peak date; equal extrema do not move that anchor.
- Structural extrema start only after the ATR warm-up, so incomplete early ATR values cannot create later floors or ceilings.
- A qualifying rejected peak becomes an active ceiling immediately.
- Later departures and failed returns increase `testCount` and record `lastTestDate`.
- Nearby overlapping ceilings merge while retaining accumulated test strength.
- Breakout, turn, and retest state updates run independently; one primary decision is selected only for display.
- The latest breakout date is retained separately, so same-candle formation of newer resistance cannot erase breakout evidence.
- An unresolved initial outside day is labelled `AMBIGUOUS_OUTSIDE_DAY` rather than assigned an invented intraday order.
- Raw replay calculations now use the anchored floor/peak ATR and the overview shows ceiling test count.
- `Already broken` rows show the persisted last fresh-breakout date directly beneath the status for manual chart validation.
- Added a second, explicitly weaker ceiling-confirmation path: a 0.5 ATR peak rejection becomes a candidate and requires two later sessions without a higher high.
- A higher high invalidates the pending compact candidate and restarts the evidence count from the newer peak.
- Confirmed ceilings now carry their origin (`STRONG_REJECTION` or `COMPACT_RANGE`) through the API and UI.
- Raw replay shows compact containment progress and uses the 0.5 ATR threshold for its automatic turn calculation.

## Decisions and tradeoffs

- The half-ATR ceiling allowance, three-ATR major-overhead distance, and two-ATR `STRONG_REBOUND` classification remain unchanged.
- Volume, delivery, close position, and 52-week distance remain evidence only.
- ta4j remains at 0.17 for this focused change; its ATR primitive is retained, while the causal swing state is implemented inside the existing engine to avoid an unrelated breaking dependency upgrade.
- The former synthetic HFCL case has only a 0.88 ATR rejection and no longer qualifies under the strict 1.0 ATR default. That is recorded as an explicit changed expectation for manual chart review.
- The 1.0 ATR rule remains the immediate confirmation path; compact containment is an alternative proof, not a global weakening of the reversal threshold.
- Both ceiling types retain the same breakout boundary: anchor high plus 0.5 peak-day ATR.

## Validation

- Ten focused Kotlin engine tests pass, including the KRN sequence: ₹1,230 candidate on 04 Aug, 1/2 containment on 05 Aug, confirmation on 06 Aug, and fresh breakout on 11 Aug. A separate regression proves that a higher high resets the compact candidate.
- Seven focused React tests pass, including ceiling-origin labels, compact containment progress in the overview and raw replay, and the correct 0.5 ATR calculation.
- Frontend production build completed successfully; the existing large-bundle warning remains.
- The full core suite currently has four unrelated baseline failures in removed RSI/Friday engines and a stale weekly-guide expectation; 280 other tests pass. Those modules were not changed here.

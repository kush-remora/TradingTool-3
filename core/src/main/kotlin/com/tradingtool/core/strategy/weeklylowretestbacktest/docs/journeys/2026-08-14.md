# Daily Low Trigger Backtest — 2026-08-14

## Feature and purpose

Reworked the previous weekly low-retest experiment into a rolling five-session backtest: every session checks the five completed sessions before it, and a qualifying low-to-high range creates a new independent limit-order setup on the current session.

## Decisions

- Every session is evaluated independently, so Day 6 and Day 7 can create separate orders from different rolling windows.
- The previous 10 sessions are split into an earlier five-session cycle and the latest five-session cycle. The latest cycle must provide the fixed +5% low-to-high confirmation; the lower low across both cycles becomes the limit-order reference. The latest-cycle low must precede its high; same-day green candles are treated as low-then-high.
- The limit offset is configurable from 0.5% to 1.0% and defaults to 0.5%; the order remains active for four sessions.
- A filled order targets the configured percentage (default 5%) above the actual buying day's low, while realized P/L remains measured from the actual fill price; it otherwise exits at the fourth trading-session close. Weekends and holidays do not consume holding sessions. No-fill hypothetical diagnostics retain the anchor-low target because no buying day exists.
- The target percentage is configurable independently through the UI/API; the +5% cycle confirmation remains unchanged.
- The 52-week-high filter is intentionally removed for this hypothesis.
- The UI supports full-watchlist and single-stock runs and retains only daily anchors that achieved the +5% trigger.
- The main row emphasizes cycle, entry, peak-after-entry, and result; raw lookback, anchor, trigger, order-window, fill-day, volume-as-percent-of-10D-average, close-near-high, sequence assumption, target reachability, and P&L fields are available by expanding a row.
- Single-stock runs now expose total realized return as a simple sum across filled trades and total holding sessions; weekends and holidays are excluded from holding time.
- Filled rows now have a daily-detail action that loads five trading sessions before the previous cycle start through five trading sessions after exit. The detail table highlights entry and exit rows and replaces the ambiguous close-from-high debug value with the daily low-to-high range percentage, while retaining OHLC, volume-vs-10D-average, delivery, close change, and close-position evidence. The modal leaves the global buy/sell calculator interactive.
- The detail table now renders close position as LOW/MID/HIGH with a compact low-to-high marker and an up/down/flat candle-direction arrow while retaining the exact percentage.
- Same-day fill/target sequencing uses the green-candle assumption; red and doji candles do not count as same-day low-to-high cycles.

## Validation

- Core engine tests: 7 scenarios cover independent Day 6/Day 7 orders, no fill diagnostics, trading-session-based fourth-session exit across a weekend, same-day green sequencing, configurable limit offset, and configurable target percentage from the buying-day low.
- Frontend page tests: 4 passed, covering watchlist and single-stock runs, raw audit values, the trade detail window/highlights, and the renamed daily range column.
- Frontend production build: passed; Vite emitted the repository's existing large-chunk warning.
- Backend compile: passed for core, models, resources, event-service, and service modules.

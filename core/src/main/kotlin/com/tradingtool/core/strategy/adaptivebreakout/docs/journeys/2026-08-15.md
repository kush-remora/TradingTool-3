# Adaptive breakout latest-date scanner — 2026-08-15

## Why

Fixed 20/40-session highs do not represent the different time stocks need to absorb supply. This feature finds a local ceiling from an actual rejected rebound and reports the first completed close above that ceiling. It is designed for watchlist observation and manual validation, not backtesting or trade execution.

## Implemented

- Added a forward-only price replay using ta4j ATR for volatility-normalized turns and ceiling width.
- Confirms a local ceiling only after a peak rejection and a later return into the same half-ATR price area.
- Demotes distant ceilings to major-overhead context after a new local floor/rebound; they remain visible but do not block a nearer breakout.
- Explicitly reports an uninterrupted rise of at least two ATR as `STRONG_REBOUND`; momentum alone cannot create a breakout.
- Added latest-date watchlist endpoints returning every stock plus up to 260 raw OHLCV decision rows.
- Added a compact React scanner with completed-close status, latest Kite LTP, live-candidate distinction, raw replay audit drawer, and neutral confirmation evidence.
- Redesigned the scanner as a single-viewport decision surface: status totals are filters, actionable states sort first, and each row visually maps floor → current price → ceiling.
- Compressed close strength, volume versus 10D, and 52-week distance into three color-coded evidence cells so the overview remains readable without opening details.
- Made each stock symbol a new-tab Kite chart link and added a small new-tab `Stock detail` link to the existing Compact Stock Review, preserving the overview/detail separation.
- Corrected confirmation semantics: live candidates use a clearly unconfirmed live candle, final current-dated Kite snapshots become completed closes after market hours, and continuation rows replay the original breakout candle's evidence.
- Added a visible evidence-source label (`Live candle`, `Market close`, `Breakout close`, or `Latest close`) to remove date ambiguity.
- Kept close-near-high, volume versus the prior 10-session average, and 52-week distance outside the breakout decision.
- Added a `20D` row action that opens the same recent-session evidence table used by the 5-Day Stock Selector.
- Made the raw decision replay non-modal and kept it below the global header so the calculator remains usable while the replay is open.
- Widened the raw replay drawer to a responsive maximum of 1,580px so the complete audit table is visible on wide screens without crowding the main scanner.
- Turned the raw replay into a teaching surface: a bottom-to-top reading instruction, the normal floor-to-breakout sequence, and definitions for Ceiling, Major, and ATR now stay above the table.
- Added consistent decision colors, row-edge markers, semantic column subtitles, and a plain-language `What this means` summary while preserving the engine's original explanation underneath.
- Compressed raw-only column widths after visual review so all columns fit at a normal 1,280px laptop viewport without horizontal interpretation loss.
- Added an accessible mini OHLC shape to every raw-replay row: H/L show the day's range, O/C show their relative positions, and green/red/neutral shows whether the close finished above/below/equal to the open.
- Explicitly labels the mini shape as position-only because daily OHLC data cannot reveal whether the session reached its high or low first.
- Persisted the original breakout candle's confirmation snapshot in the scan response, preventing older breakouts from silently falling back to the latest candle after raw replay truncation.

## Decisions and tradeoffs

- Completed daily close is the confirmed signal. LTP can only show `LIVE_CANDIDATE` because the current session may still fail.
- Five years of candles warm the ATR and reconstruct state; this is computation history, not a fixed breakout lookback.
- The active ceiling is local: a level more than three ATR above a newly confirmed floor is retained as major overhead, not used as the local breakout gate.
- A fresh breakout still requires the first completed close above a confirmed local ceiling. The two-ATR rule changes status only; it never bypasses resistance confirmation.
- No backtest, target, stop, score, or order action was added.
- Color communicates state or evidence only. Text, icons, and exact numbers remain present so color is never the sole signal.
- The shared Adaptive Breakout raw rows contain OHLCV but not delivery data, so the popup shows `—` for Delivery rather than implying unavailable evidence.
- If persisted breakout evidence is unexpectedly unavailable, the UI keeps the original breakout date visible and shows unavailable metrics; it never substitutes another candle.

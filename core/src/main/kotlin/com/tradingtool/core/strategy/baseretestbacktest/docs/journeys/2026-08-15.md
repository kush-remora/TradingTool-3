# Three-Touch Base Backtest — 2026-08-15

## Why

Test whether two lows within 1%, separated and confirmed by 5% rebounds, create a useful support base for a third-visit limit entry. The console supports a complete saved watchlist or one stock from that watchlist.

## Implemented

- Chronological base detector with no overlapping setups per stock.
- Next-session buy limit at 1% above the lower low.
- Configurable target and stop loss, gap-aware fills/exits, conservative stop-first handling when daily OHLC cannot reveal sequence, end-of-data close exits, P/L, and trading-session holding days.
- Kotlin API/service wiring and a compact React/Ant Design console with summaries, audit rows, and daily detail.

## Decisions and tradeoffs

- Only completed candles confirm a base; the order starts on the following trading session to prevent look-ahead.
- A resting buy limit can fill before that same session later closes below the base. Close-based invalidation therefore cancels only an order that was not already executable earlier in the session.
- This is a support-base experiment, not proof of Wyckoff accumulation; volume and structural validation remain outside this backtest.
- Base discovery is independent of target and stop-loss timing. Changing exit parameters changes trade outcomes, not which completed bases are detected.

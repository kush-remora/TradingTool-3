# NETWEB Cycle Tracker — 2026-08-08

## Feature and rationale

Build a stock-specific daily tracker for NETWEB so the user can distinguish a range-bound 5% rotation from a larger expansion run and from a drawdown/reset.

## Implemented

- Added a deterministic `NetwebCycleEngine` with `WEEKLY_ROTATION`, `BULL_RUN`, `DRAWDOWN`, and `NEW_BASE` states.
- Added configurable base, breakout, drawdown, and stabilization thresholds in `netweb_cycle_config.json`.
- Added explainable daily snapshots, phase segments, active base boundaries, expansion peak, returns, volume ratio, confidence, and candidate action.
- Added `POST /api/strategy/netweb-cycle/run` and a fixed NETWEB frontend page under `NETWEB Cycle Tracker`.
- Added focused Kotlin and React tests.

## Key decisions and tradeoffs

The engine uses a replayable state machine instead of a predictive model. A 5% move is evaluated against the active base and expansion peak, so a range-contained move remains rotation while a strong move above the base can start a bull run. Delivery data is intentionally not included in this first slice; the current phase evidence uses price and volume while the state behavior is reviewed.

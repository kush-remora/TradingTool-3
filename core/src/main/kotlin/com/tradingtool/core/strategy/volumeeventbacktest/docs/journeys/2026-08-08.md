# Volume Event Confirmation Backtest — 2026-08-08

## Why it was built

The Volume Event Review showed raw volume shocks and low RSI, but it did not test whether waiting for RSI to improve produced a cleaner 5% continuation entry. This feature supports a detailed selected-stock review first and a broader watchlist validation using the same rule.

## What was implemented

- Added a reusable per-symbol event engine for volume ≥2× the prior 5-session average with rolling stock-specific RSI calibration.
- Added five-session RSI confirmation, next-session-open entry, a 5% target, and a 15-session target-only evaluation window.
- Added a five-session price-context gate: the event close must be at least flat versus five sessions earlier and no more than 5% below the prior-five-session peak close.
- Replaced the fixed RSI(14) <=35 gate with a rolling stock-specific RSI ceiling learned from completed prior-year event outcomes.
- Added an early-entry mode that requires event-day RSI to be higher than RSI five sessions earlier, then enters at the next session open.
- Recorded failed confirmations, insufficient-forward-data events, overlapping events, target hits, and unresolved trades in the audit trail.
- Added pooled and per-symbol watchlist summaries through a single backtest API.
- Added a frontend page with selected-stock and whole-watchlist modes.

## Key decisions and tradeoffs

- The first version uses fixed parameters and does not permit stock-specific tuning.
- Events are non-overlapping per stock so pooled watchlist results do not double-count simultaneous positions.
- No stop-loss is modeled yet; unresolved trades close at the evaluation-window close and display that return explicitly.
- The future-five-session confirmation mode remains available as the comparison benchmark; early entry is not treated as having the same confidence.

## Validation

- Volume-event engine and adaptive RSI calibration tests: 5 passed.
- Frontend page tests plus the existing volume-event review tests: 4 passed.
- Frontend production build: passed; Vite retained the existing large-bundle warning.
- Resource and service Maven compile: passed.

## Final decisions

- Confirmation rate uses only events with a completed five-session confirmation decision.
- Events skipped while another simulated trade is open and events without enough forward candles are counted separately in the audit.
- The default backtest period is six months; callers can still provide explicit ISO from/to dates.
- Bearish-context rejections remain in the audit with their five-session return and drawdown measurements.
- Adaptive RSI calibration uses 252 prior trading sessions, 5-point RSI bands, and no fallback threshold when evidence is insufficient.
- Early-entry RSI trend uses only t-5 through t-1, excluding the event date; the audit now shows both the change and PASS/FAIL filter result.

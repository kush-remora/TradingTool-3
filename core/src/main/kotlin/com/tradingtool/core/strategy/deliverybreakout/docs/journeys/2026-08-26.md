# Delivery Breakout Result vs Effort Tabs

## Feature and purpose

Added a focused review view for delivery/volume events where the stock showed limited intraday price movement. This helps separate effort (unusual delivery or volume) from immediate result (the event candle's low-to-high spread).

## Implemented

- Kept the existing `All Stocks` event table unchanged.
- Added a `Result vs Effort` tab that retains only rows with event-day low-to-high movement below 3%.
- Added an `At Least 10% Below 52W High` tab that refines the Result vs Effort rows, retaining only stocks whose current price is at least 10% below the event-date 52-week high.
- Added a `20D Accumulation Candidate` tab that refines the 52W-filtered rows.
- Defined the filter as `(event high - event low) / event low * 100 < 3`.
- The 52-week filter uses live LTP when available and event close as fallback.
- Added backend-computed pre-event metrics: quiet-session count, 20-session range percentage, and candidate flag.
- Added pre-event 10-session total-change percentage and upward-direction flag.
- Result vs Effort now requires the pre-event ten-session change to be positive and below 10% in addition to the event-day Low→High rule.
- The accumulation candidate uses the 20 completed sessions before the event (about one month) and requires at least 10 of 20 sessions to have Low→High movement at most 2%, with the complete 20-session range at most 10%.
- Kept the filter client-side because `event_low` and `event_high` are already part of the dashboard response.
- Preserved the existing event-type, minimum-volume-ratio, and minimum-delivery-ratio filters inside both tabs.

## Key decision

The threshold uses the event candle's intraday low-to-high range, not delivery percentage or close-to-close change. The tab is a review lens and does not change backend event detection.

The 52-week tab inherits the Result vs Effort condition before applying its location check. It does not alter the historical event calculation and avoids treating a stock near its yearly high as equivalent to one with the same delivery shock near a lower base.

The accumulation tab inherits the 52-week location check and uses only sessions before the event date, preventing the event candle itself from influencing the accumulation classification.

The Result vs Effort upward check uses the first and last closes in the same ten-session pre-event window. A positive change below 10% is considered upward but not overextended; negative or 10%+ movement is excluded from Tab 2 and therefore from Tabs 3 and 4.

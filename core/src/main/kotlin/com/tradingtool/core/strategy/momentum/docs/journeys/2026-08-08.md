# Watchlist 30-Day-Low Move Evidence — 2026-08-08

## Why it was built

The watchlist evidence summary needed one compact, objective measure of how far each stock had already moved from its recent price floor. A move of at least 10% above the latest 30 completed trading-session low is surfaced as momentum evidence for manual prioritisation, without turning it into a recommendation or score.

## What was implemented

- Added the latest 30-session low and close-to-low percentage to the shared Kotlin momentum evidence contract.
- Added a sortable `Move from 30D low` column to the watchlist evidence summary.
- Used live LTP when available and latest close otherwise; retained a daily-data fallback for older responses without the new contract fields.
- Added a `≥10% move` visual cue and displayed the underlying low price for each stock row.
- Updated Volume Event Review detail rows to display the selected events newest-first while preserving volume-based ranks and the rank-1 strongest-event summary.
- Added TA4J RSI(14) at each volume-event date and exposed it as an `RSI 14` column in Volume Event Review.
- Changed shared volume-event detection to compare against the prior 5 trading-session average and updated the Volume Event Review labels accordingly.

## Key decisions and tradeoffs

- Interpreted “past 30 days” as the latest 30 completed trading sessions so weekends and market holidays do not shorten the evidence window.
- Kept the metric as raw price-distance evidence; no ranking score or trading recommendation was added.

# Four-Day Close-Strength Backtest — 2026-08-22

## Feature and purpose

Added a price-action inspection backtest for four consecutive green daily candles where every close is at or above a configurable percentage of that candle's high-low range. The screen supports a single NSE stock or an existing watchlist and scans the latest 60 calendar months.

## Implementation

- Added a dedicated Kotlin engine, service, API endpoint, and DI bindings.
- Added a React route with a default 80% close-location threshold.
- Each signal row shows its date and four close-location values.
- Each signal opens the 20 trading sessions ending on the signal date with OHLCV, daily move, and close-location fields.
- Stock symbols and the detail view link to the NSE instrument chart in Kite.

## Decisions and tradeoffs

- The signal is rolling: a five-day qualifying run produces a signal on both the fourth and fifth sessions.
- This slice intentionally reports evidence only; it does not add an entry, target, stop, volume filter, or trade outcome.
- The API requests a 60-month window plus a 60-calendar-day buffer so the first signal can still display its preceding 20 trading sessions.

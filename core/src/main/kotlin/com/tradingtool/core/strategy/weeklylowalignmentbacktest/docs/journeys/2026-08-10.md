# Weekly low alignment backtest — 2026-08-10

Implemented a standalone six-month watchlist backtest for weekly-low alignment. The engine uses the previous completed week's low as `L`, accepts a current-week low within 1% only after a five-trading-session gap, enters at `L × 1.01`, applies a configurable target, and has no stop-loss. Unreached positions time-exit at the configured maximum holding period. The current incomplete week is excluded and overlapping positions for a stock are skipped.

Validation: focused Maven tests pass for the too-soon DMART case, qualifying five-session retest, configurable target, and negative time exit. The API/resource module compiles successfully.

# Friday Close-Strength Backtest — 2026-08-14

## Retirement

The experiment was removed from the application after review of the six-month sample showed an insufficiently reliable edge. The implementation, API route, navigation entry, and tests were deleted; this journal is retained as the historical record.

## Feature and purpose

Added a six-month watchlist backtest to test whether a Friday close near the top of its daily range, combined with a Friday gain above 2% from Thursday's close, is followed by useful upside during the next trading week.

## Implemented

- Reused the existing saved watchlist/index membership source.
- Defined the signal as close position in Friday's range `>= 70%` and Friday close-to-Thursday close `> 2%`.
- Entered at the next available trading session's open and measured the following completed week's highest high.
- Added a realistic fixed-exit path: +5% target if reached by Wednesday; otherwise exit at Thursday's open.
- Added average, median, and threshold-rate summary metrics plus a row-level audit table.
- Added realized return, target-hit/Thursday-open exit counts, and worst realized return to expose downside.
- Added Friday volume, prior-10-session average volume, and percentage change versus that baseline.
- Made the audit table dense with one-line exit details, no pagination, and viewport-height scrolling.
- Added `POST /api/strategy/friday-close-strength-backtest/run` and a navigation page.

## Decisions and tradeoffs

- The result is explicitly a retrospective maximum-upside metric, not an executable exit or a claim of realized return.
- The realistic return is separate from maximum upside: target hits are capped at +5%, while Thursday-open exits may be negative.
- Volume comparison is percentage change from the prior 10 trading sessions, not a same-week or post-signal average.
- A Friday without a Thursday candle is skipped; a following week without data or the current incomplete week is excluded.
- Monday holidays use the first available session as the entry day; if Thursday is a holiday, the next available session is used for the fallback exit.

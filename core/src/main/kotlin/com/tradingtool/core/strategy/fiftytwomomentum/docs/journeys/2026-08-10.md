# 52W Momentum Rule 5

## Why it was built

Rule 5 now provides a simple five-session 52-week breakout watchlist view. The previous CSV upload and 200-SMA proximity analysis did not match the intended workflow.

## Implemented

- Added multi-watchlist selection and automatic scan results on the frontend.
- Added watchlist and scan API endpoints backed by active index constituents.
- Unioned selected watchlists and evaluated each symbol once.
- Added a selectable breakout period of 20D, 40D, 60D, 100D, or 200D.
- Defined the selected N-day reference as the highest daily high across the preceding N trading sessions.
- Added a configurable near-high tolerance. A 2% setting accepts a current close of ₹98 against a prior period high of ₹100, and the signal fires only when the close first enters that accepted band.
- Applied the same prior-high and tolerance rule to live scans and the six-month backtest; result fields now distinguish the signal close from the prior period high.
- Added the age of the prior period high in trading sessions. When the same high occurs multiple times, the UI reports the most recent occurrence.
- Added a six-month backtest using breakout-day close entries and a 10% target. Target exits occur on the first later session whose high reaches the target; unhit positions remain open through the backtest end.
- Added two backtest result tabs: detailed signals include skipped signals while a position is open, and entered trades show only actual positions.
- Added backtest-end LTP and percentage move from entry to the entered-trades tab. LTP is the latest available close through the requested backtest end date.
- Made entered-trade symbols open the corresponding NSE instrument chart in Kite in a new tab.
- Showed each matching stock with its latest fresh breakout details and expandable fresh breakout days from the latest five trading sessions.

## Decisions and tradeoffs

- The five-day result window means five trading sessions, not five calendar days.
- The current close is compared with the rolling maximum high across the previous N sessions; this matches the intended 20D/40D/60D/100D/200D high reference.
- `0%` requires the close to be strictly above the prior high. A positive tolerance accepts closes at or above the lower bound and suppresses repeat signals until price leaves the accepted band.
- Prior-high age is measured as the trading-session distance from the signal day to the latest matching high inside the selected N-session reference window.
- Backtest history includes an additional pre-period buffer so the selected 200D reference can be evaluated from the first day of the six-month test window.
- No SMA, volume, delivery, market-cap, sector, or close-confirmation filters are applied.

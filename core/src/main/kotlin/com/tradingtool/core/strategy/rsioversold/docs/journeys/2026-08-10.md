# RSI low scanner

The RSI oversold backtest was removed and replaced with a simple multi-watchlist scanner. It calculates daily RSI-14 for each selected stock, finds the minimum RSI over the 200 trading sessions immediately before the signal window, and qualifies a stock when any of the latest 20 sessions has `RSI + 1` equal to that baseline minimum. The response uses the most recent qualifying session and returns its RSI, date, close price, volume, baseline minimum, latest daily fallback close/volume, and watchlist memberships. Duplicate symbols across selected watchlists are scanned once.

The API exposes `GET /api/strategy/rsi-oversold/watchlists` and `POST /api/strategy/rsi-oversold/scan`. The response separates `insufficientDataSymbols` from `noSignalSymbols`, so a normal zero-signal scan does not look like a data failure. The React page supports one or more watchlists and combines the historical response with the existing `/api/stocks/quotes` feed for current LTP, current volume, and percentage change from the signal candle price. No target or simulated trade behavior remains.

Validation outcome: `mvn -q -pl service -am test -Dtest=RsiOversoldScannerEngineTest -Dsurefire.failIfNoSpecifiedTests=false -Dkotlin.compiler.execution.strategy=in-process` passed; the focused React tests (3) and frontend production build passed. The engine tests cover the prior-200-session baseline, the excluded 20-session signal window, and insufficient history; the scan response now keeps no-signal stocks separate from insufficient-data stocks.

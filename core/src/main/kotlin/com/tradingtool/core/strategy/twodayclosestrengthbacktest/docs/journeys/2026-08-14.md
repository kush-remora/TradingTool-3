# Two-Day Close-Strength Backtest — 2026-08-14

## Feature and purpose

Added a six-month watchlist backtest for a five-session pattern where the first three closes are below 80% of their daily ranges and the final two closes are at or above 80%.

## Decisions

- Entry is the next available session open after the five-session pattern, normally Monday.
- A fixed 5% target is checked through Wednesday using intraday highs.
- Unreached targets exit at Thursday close; a Thursday holiday uses the next available session close.
- The current incomplete week and incomplete following trade week are excluded.
- The audit reports the five close-position percentages and realized return for each completed trade.

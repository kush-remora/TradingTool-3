# Compact review watchlist navigation — 2026-08-12

## Why

Daily review needs an active watchlist flow: open one compact stock page, read it, take a note, then move to the previous or next stock without returning to a separate list screen.

## Implemented

- Added `GET /api/stocks/watchlists/{watchlistKey}/members`.
- Resolves watchlist keys case-insensitively and returns active NSE members in symbol order using the existing instrument-search response shape.
- Keeps independent stock search unchanged; the frontend only uses the endpoint when a watchlist is selected.

## Validation

- `mvn -pl resources -am -DskipTests compile`
- `mvn -f pom.xml -pl service -am package -DskipTests`
- Live endpoint check performed after restarting the local service.
